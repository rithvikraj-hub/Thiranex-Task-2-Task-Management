## Project Overview

This project is a Task Management Web Application developed as part of the Thiranex Internship Task 2.  
It allows users to create, view, and delete tasks using a responsive frontend interface connected to a Node.js and Express.js backend API.

---

## Features

* User-friendly interface
* Add new tasks
* View all tasks
* Delete tasks
* Backend API integration
* Responsive design for web and mobile screens

---

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js
* CORS
